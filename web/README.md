# Ego Labs — web

Next.js (App Router) + TypeScript + Tailwind CSS. See the [root README](../README.md) for setup and the [spec](../docs/ego-labs-phased-spec.md) for scope.

| Path | Contents |
| --- | --- |
| `app/page.tsx` | Public landing page at `/`. Signed-in visitors go on to `/profile`, then `/dashboard`. |
| `app/profile/` | Profile: who you are, what's on your desk, and the way into the dashboard. Where sign-in lands. |
| `app/(app)/` | Routes inside the app shell. `dashboard/` is the Overview; `[...slug]` serves every not-yet-built page. |
| `components/shell/` | App shell: top bar with section pills and page tabs, and a navigation drawer on narrow screens. |
| `components/ui/` | Design-system components. |
| `components/theme/` | Light/dark toggle. Colour tokens live in `app/globals.css` as `light-dark()` pairs. |
| `lib/nav.ts` | Sections, pages, and the phase that builds each page. |
| `lib/pipeline.ts` | The nine pipeline levels; each level's status comes from its pages in `lib/nav.ts`. |
| `app/(auth)/` | Sign-in and registration pages. |
| `proxy.ts` | Redirects signed-out visitors to `/login` (except from the landing page). |
| `lib/auth/` | Session cookie, server actions for sign-in/registration/sign-out. |
| `lib/api/` | Server-side API client. `openapi.json` and `schema.ts` are generated by `make gen-api` — don't edit them. |
| `tests/` | Vitest + Testing Library. |

Adding a real page: create its route folder under `app/(app)/`, then set `built: true` on its entry in `lib/nav.ts`.
